1. Yêu Cầu Hệ Thống

🖥️

Phần cứng

RAM 4GB trở lên, ổ cứng còn trống 500MB

🌐

Trình duyệt

Chrome 90+, Firefox 88+, Edge 90+ hoặc Safari 14+

📡

Kết nối mạng

Kết nối Internet ổn định (khuyến nghị 10Mbps+)

📱

Thiết bị di động

Hỗ trợ responsive trên mọi thiết bị

⚙️ Yêu cầu cho Developers (Self-hosted)
  • Node.js phiên bản 18.0.0 trở lên
  • NPM phiên bản 9.0.0 trở lên
  • Git để clone source code
  • PostgreSQL hoặc SQLite cho database
🔧

2. Hướng Dẫn Cài Đặt

📦 Cài đặt từ Source Code
Clone repository
git clone https://github.com/kteam/courtify.git
cd courtify
Cài đặt dependencies
# Cài đặt các thư viện cần thiết
npm install
Cấu hình môi trường

Tạo file .env trong thư mục root với nội dung:

DATABASE_URL=file:./dev.db
JWT_SECRET=your-secret-key
PORT=3000
Khởi tạo database
# Chạy migration và seed data
npm run db:migrate
npm run db:seed
Khởi động ứng dụng
# Chạy cả frontend và backend
npm run dev

Ứng dụng sẽ chạy tại: http://localhost:5173

💡 Mẹo

Sử dụng tài khoản mặc định để đăng nhập: admin@courtify.vn / admin123

4. Tổng Quan Dashboard

Dashboard là trang tổng quan giúp bạn nắm bắt nhanh tình hình hoạt động của sân.

Giao diện Dashboard với các thống kê quan trọng
✨ Các thành phần chính
  • Tổng quan nhanh: Số lượng đặt sân hôm nay, doanh thu, sân trống
  • Biểu đồ doanh thu: Theo dõi xu hướng doanh thu theo tuần/tháng
  • Lịch đặt sắp tới: Danh sách các đặt sân trong ngày
  • Tìm kiếm nhanh: Tìm khách hàng, booking theo từ khóa
📅

5. Đặt Sân & Lịch

Quản lý lịch đặt sân trực quan với nhiều chế độ xem: Ngày, Tuần, Danh sách.

Giao diện lịch đặt sân theo ngày với các slot thời gian

5.1 Tạo đặt sân mới

Nhấn nút "Đặt sân mới"

Nút màu xanh ở góc trên bên phải màn hình

Điền thông tin đặt sân

Chọn sân, ngày, giờ bắt đầu và kết thúc

Chọn khách hàng (nếu có)

Tìm và chọn khách hàng từ danh sách hoặc để trống cho khách vãng lai

Xác nhận đặt sân

Nhấn "Đặt sân" để hoàn tất

Form đặt sân mới với tính năng kiểm tra trùng lịch tự động

5.2 Check-in / Check-out

Click vào một booking trên lịch để mở panel chi tiết. Từ đây bạn có thể:

  • Check-in: Xác nhận khách đã đến chơi
  • Check-out: Kết thúc và tạo hóa đơn thanh toán
  • Chỉnh sửa: Thay đổi thời gian, thêm ghi chú
  • Hủy: Hủy lịch đặt nếu khách không đến
👥

6. Quản Lý Khách Hàng

Theo dõi thông tin khách hàng, lịch sử đặt sân và chương trình thành viên.

Danh sách khách hàng với thông tin hạng thành viên
🏆 Hệ thống thành viên
  • Bronze: Khách hàng mới, ưu đãi 5%
  • Silver: Đặt từ 10 lần, ưu đãi 10%
  • Gold: Đặt từ 30 lần, ưu đãi 15%
  • Platinum: Đặt từ 50 lần, ưu đãi 20%
